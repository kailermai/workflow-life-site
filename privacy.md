# workflow-life privacy policy

Last updated: 22 November 2026.

workflow-life is a personal tool. It is used only by its developer, with their own Google account. It has no other users.

## What it accesses

With the user's permission, it uses the Google Tasks API, with the scope `https://www.googleapis.com/auth/tasks`, and asks for nothing else in the Google account. It reads the user's task lists and tasks, and adds tasks. The only task lists it can create are these four: Todo, Someday, School and To buy. It changes the title, date or status of tasks it added itself. It never deletes a task or a list.

## What it does with it

It keeps a copy of the tasks in a folder on the user's own computer, which the user's own cloud storage backs up. The sign-in is kept in the computer's own credential store.

## What it never does

It sends Google user data to no one. It has no server of its own, shares nothing with other companies, sells nothing, and uses no advertising or analytics.

## Limited Use

workflow-life's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

Access can be removed at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
