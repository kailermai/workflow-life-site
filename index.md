# workflow-life

workflow-life is a small personal tool that keeps my own to-do list in Google Tasks. Only I use it: it runs on my own computer, when I start it.

Each time I run it, it:

- adds my school assignments, and reminders for my classes and exams, to my task lists;
- adds the to-dos I noted down since the last run;
- saves a copy of my tasks to my own cloud folder.

It asks Google for access to Google Tasks only, and to nothing else in my account. It never deletes a task.

Read its [privacy policy](privacy.html).
